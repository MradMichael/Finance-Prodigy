# Demo

`momentum-planner.jsx` is a standalone interactive planner — the debt payoff
simulation and rollover waterfall running on sample data, no backend
required. **A design reference, not part of the running app**: it has no
`package.json` and no build tooling of its own, and isn't imported by
anything under `client/` or `server/`. See the repository root
[`README.md`](../README.md#demo) for how it's used.
